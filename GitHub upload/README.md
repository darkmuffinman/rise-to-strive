# Rise To Strive

A season of goals, one day at a time — quests, a level counter that goes to 30, and a PS1-style chibi character that grows with you. Frutiger Aero × life-sim.

- **Play it:** open the site, press **Start**, and either make a **New save** or **Import save** with a save file you exported earlier.
- **On iPhone:** open the link in Safari → Share → **Add to Home Screen**. It opens full-screen and works offline after the first visit.
- Your data never leaves your device: progress is stored in your browser, and **More → Save a copy** gives you a file you can keep or move.

Everything is one self-contained HTML file (Three.js is bundled inside). The 3D character kit and environments were built in Blender with the scripts in the `blender/` folder of the project.
